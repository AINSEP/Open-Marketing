Reports use half-open UTC midnight windows (1–366 days), one submission, six polls, five injected waits and a total 60s abort deadline. Each RPC has a 15s abort timeout; the host injects both timers through `timeoutSignal({ milliseconds })`, and injected effects must honor cancellation. Success with nil URL yields `no_data`; exhausted polling yields `expired`; reported zero values remain strings. Spend and ConversionsQualified preserve decimal text, without summing, FX or rounding. Malformed/foreign/duplicate rows reject atomically. ZIP: one ordinary file, 2MiB compressed, 8MiB expanded, 10,000 rows. Fixed scalar TSV supports fully quoted or unquoted fields, without embedded quotes/newlines. Numeric JSON IDs outside JS's exact integer range reject. Campaign responses over 1,000 entities/1MiB reject; account pages cap at 100 and index 10,000, with explicit continuation/limit signals.

Every RPC and report download enters the same server policy/audit gateway with its current scope, binding, operation ID and read-effect digest. The wire request union now includes a credential-free `GET` for downloads, alongside `POST` JSON RPCs. Download admission/binding denial stops before the download adapter; guarded download must also recheck after awaits. Receipts use the parsed operation ID snapshot, even when the caller mutates its original input.
