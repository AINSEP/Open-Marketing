# Twilio SMS — R1 reads/auth

After host integration, `om_twilio_account_status` and `om_twilio_sender_status` inspect an account and one configured Messaging Service/sender. Service, number membership/capabilities, brand, campaign and toll-free verification are separate observations; every result keeps `sendReadiness:"unknown"`. Accounts 401/403 yields `permission_limited` with null data: a valid Standard key can receive 401/20003, so authentication and permissions remain uncertain ([Twilio explanation](https://help.twilio.com/articles/50301225354651)). Do not request a broader key just for this read.

Imports/factories are inert; the plugin ships disabled/unadmitted, blocking credential access and egress. The server supplies configuration, sealed credential broker, current-policy gateway, fetch, clock, observer and **`deadlineSignal({ timeoutMs })`** to `createTwilioSmsAdapter`; invoke with `adapter.invoke({ context, operationId, command }, { signal })`. The host must return a fresh signal expiring within the requested 15,000ms and supply fetch that honors it through body consumption; e.g. `deadlineSignal: ({ timeoutMs }) => AbortSignal.timeout(timeoutMs)`. No plugin wall-clock timer is constructed. Missing/throwing deadline creation returns unavailable before fetch. The broker provides Account SID + API Key SID + secret; a separately sealed account Auth Token is needed later for webhook verification.

Each invocation validates scope/connection and resource bindings, performs at most one fixed HTTPS GET without redirects/retries, and reads at most 64KiB. Provider extras are stripped. Gateway/broker errors retain only the code and a fixed message with `retryable:false`; provider text, secrets, phone addresses and retry authority never reach errors or telemetry. The gateway owns current admission/ownership/plugin-revision checks and durable pre-egress audit with context IDs. Brand responses lack account_sid, so their configured ownership must be established by the host.

`mcp.json` has no external server. Alpha's `@twilio-alpha/mcp` 0.7.0 (MIT, stdio, API-key Basic authentication) generates GET/POST/PUT/DELETE operations; hosted Twilio MCP only searches/retrieves documentation.
